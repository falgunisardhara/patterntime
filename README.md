PatternTime

An Interactive AI/ML Time-Series Investigation Laboratory

PatternTime is a locally running tool designed to help developers investigate changes and anomalies in time-series data.

Project Goals

Import and validate timestamped metric data from CSV files.

Visualize time-series metrics using interactive charts.

Detect significant changes and unusual behavior.

Compare metrics before and after detected changes.

Evaluate detection algorithms using datasets with known changes.

Compare detection performance using measurable evaluation metrics.

Planned Technology Stack

Backend: Laravel

Data analysis and ML: Python, NumPy, Pandas, and suitable detection libraries

Visualization: Apache ECharts

Storage: SQLite

Privacy and Execution

The project is designed to run locally without requiring paid AI APIs or cloud-based processing.

Development Status

Initial development: environment setup and time-series data preparation.
